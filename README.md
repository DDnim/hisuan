# 嗨算！

越算越嗨的竖式算术练习。仿照「ドパドリル」（[@grmchn4ai 的视频](https://x.com/grmchn4ai/status/2103807453406388538)）的玩法做的。

**在线玩：https://wtome.com/play/hisuan/**

用浏览器直接打开 `index.html` 就能玩（没有依赖，也不用构建）。

- 按年级选模式（对应人教版单元，选择会记住）：

  | 模式 | 内容 | 形式 |
  |---|---|---|
  | 学前 | 数一数、看图做10以内加减 | 图画（🍎 等图案） |
  | 一上 | 10以内加减、20以内进位加法 | 口算（横式） |
  | 一下 | 20以内退位减法、100以内口算 | 口算 |
  | 二上 | 100以内笔算加减、表内乘法 | 竖式 + 口算 |
  | 二下 | 表内除法、有余数的除法 | 口算（余数也要填） |
  | 三上 | 万以内加减、多位数乘一位数 | 竖式 |
  | 三下 | 除数是一位数的除法、两位数乘两位数 | 竖式 |
  | 四上 | 三位数乘两位数、除数是两位数的除法 | 竖式 |

  整数的加减乘除到四上就学完了。四下以后是四则混合运算、小数，还没做
- 口算从左往右填；答错后会出现方法提示（凑十、破十、想口诀）
- 竖式一次填一位：加减乘从个位往上填（显示进位、退位）；两位数乘法先填每行的部分积再相加；除法从商的最高位填，每填一位展开一行乘积和余数
- 每答对一位，「嗨值」就会涨，单位一路从万、亿、兆升到不可思议，最后变成 ∞
- 答得越多，特效越夸张：三角彩旗 → 彩色键盘 → 放射光 → 小伙伴 → 彩带、烟花
- 每答对一位，按下的键会射出一道光到答案格。连对会显示计数，5 连对起卡片发光，每 5 连对放一轮烟花
- 一次答对率 80% 以上解锁 EX：20 秒的狂热模式，每答对一题 +10 分
- 有背景音乐（C–Am–F–G 循环），特效等级越高，乐器越多、节奏越快；每连对一次再快一点、高半音（最多 12 次），答错就回到原样；EX 时再提速、升八度
- 可以用键盘的数字键、Backspace、Enter 操作。音效和音乐都用 WebAudio 现场合成，「声音」开关一起控制

参考视频放在 `ref/`，不进 git。

## 录制游戏画面（做视频用）

```sh
node tools/record-ex.js 三年级上   # 在无界面 Chrome 里自动玩到 EX，录下画面和声音 → rec/
sh tools/mux-ex.sh                 # 以画面里的横幅为基准对齐音画 → rec/hisuan_ex.mp4（1080×1920，30fps）
```

需要 Chrome、ffmpeg 和 `puppeteer-core`（放在别处时用 `PUPPETEER=<路径>` 指定）。`rec/` 不进 git。
